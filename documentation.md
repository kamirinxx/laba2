# Документация
***Библиотека вычисляет геометрические параметры фигур: площадь и периметр.***

**Circle (circle.py):**

*Площадь:*  = \pi r^2$  

*Периметр (длина окружности):*  = 2 \pi r$

**Square (square.py):**

*Площадь:*  = a^2$

*Периметр:*  = 4a$


## circle.py
*Функция* **area(r)** *получает на вход радиус окружности и выводит площадь круга:*

     def area(r):
         return math.pi * r * r

*Например:* получает на вход 6 выводит 113,04..

*Функция* **perimeter(r)** *получает на вход радиус и выводит периметр окружности:*

    def perimeter(r):
        return 2 * math.pi * r

*Например:* получает на вход 8 выводит 50,24..

## square.py
*Функция* **area(a)** *получает на вход сторону квадрата и выводит его площадь:*

    def area(a):
        return a * a

*Например:* получает 6 выводит 36


*Функция* **perimeter(a)** *получает на вход сторону выводит периметр квадрата:*

    def perimeter(a):
    return 4 * a

*Например:* получает 6 выводит 24
